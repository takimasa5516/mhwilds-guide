# モンスターハンターワイルズ 総合攻略データベース (MHWilds Guide Portal)

『モンスターハンターワイルズ（MONSTER HUNTER WILDS）』の最新攻略情報を集約した、スマホファースト対応の総合戦略Webアプリケーションです。

---

## 🌟 主な機能

### 1. 最新環境 最強装備データベース（Tier SS / Tier S+）
- **白熾龍ゾ・シア × 古代遺構アーティア「古代の英知」複合キメラ**
  - ラスボス「白熾龍ゾ・シア」防具の【白熾の波動】と「アーティア防具」の破格スロット・シリーズスキル【古代の英知】を完全反映したエンドコンテンツ結論装備。
- **全14武器種の最強テンプレ**
  - 会心100%超会心物理ビルド、属性特化ビルド、高難度マルチ向け麻痺・広域化支援ビルドなど。

### 2. 武器種別 5大属性（火・水・雷・氷・龍）特化装備
- アジャラカン（火）、ウズ・トゥナ（水）、レ・ダウ（雷）、ジン・ダハド（氷）、神剣ゾ・シア（龍）など、各属性環境に完全特化した最高峰武器と推奨スキル構成。

### 3. 操作・立ち回り優位性解説（コンボ単体にとどまらない戦略）
- 相殺判定のフレーム有利・攻撃権の強奪
- 集中モードによる360度弱点定点照射
- ジャストガード＋攻めの守勢によるスタン値＆火力1.15倍同時奪取
- 片手剣の抜刀アイテム・スリンガー即応アドバンテージ

### 4. ウィッシュリスト × 素材 × 対象モンスター討伐数シミュレーター
- 作りたい武器・防具・装飾品を選択し手持ち素材の所持数を入力するだけで、
  - **期待討伐数（平均）**: 1狩猟あたりの期待ドロップ個数から算出
  - **90%安心討伐数（統計的確証）**: レア素材（宝玉など）の偏りを二項分布・ポアソン近似でシミュレート
  - **【逆引き】今狩るべきモンスター一覧** をリアルタイム表示。

### 5. 古代遺構アーティア装備 ＆ 護石錬金・神おま完全攻略
- アーティア防具5部位の破格スロット性能（④④①など）とキメラ採用理由
- マカ錬金3種（幽玄・輪廻・神気錬金）の解放条件と対象スキル
- Sランク神おま厳選早見表
- 限界突破強化手順

### 6. モンスター図鑑＆弱点・肉質早見表（全20体完全網羅）
- 白熾龍「ゾ・シア」、鎖刃竜「アルシュベルド」、雷迅竜「レ・ダウ」、波衣竜「ウズ・トゥナ」、黒炎を纏うヌ・エグドラ、ジン・ダハド、ラバラ・バリナなど全20体の弱点属性（★0〜★3）、状態異常耐性、破壊可能部位、危険技の予備動作と対処法。
